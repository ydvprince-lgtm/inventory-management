# 📦 Cloud-Based Inventory Management System

A dynamic, cloud-ready web application built to manage, track, and visualize inventory efficiently in real time.

---

## ✨ Features

- **📊 Interactive Dashboard:** Visual representation of stock data and analytics using interactive charts.
- **🌓 Light / Dark Theme:** Toggle between light and dark modes for a better user experience.
- **📦 Stock & Item Tracking:** Easily add, edit, and monitor inventory items.
- **☁️ Cloud Deployment Ready:** Pre-configured with `Procfile` for quick deployment on platforms like Render, Railway, or Heroku.
- **🎨 Responsive UI:** Clean and responsive interface using custom templates and static styling.

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3, JavaScript
- **WSGI Server:** Gunicorn (configured via `Procfile`)
- **Version Control:** Git & GitHub
